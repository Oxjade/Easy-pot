EASYPOT

Decoys

Exposed .env files, .git directories, database dumps, admin logins and internal API docs, matched to your stack. Any decoy that would clash with a real page is switched off at startup.

Integrate

In front of your app in an afternoon.

  1. Run it next to your app with Docker.
  2. Point traffic at it: DNS, your load balancer or nginx.
  3. Connect alerts: Slack, Wazuh or your SIEM.
  4. Push blocks to your firewall feed.

No code changes. Your app gets X-EasyPot-Score on every request if it wants to use it.

# EasyPot in front of your app on :3000
docker run -d -p 8080:8080 \
  -p 127.0.0.1:8081:8081 \
  -v easypot-data:/var/lib/easypot \
  -e EASYPOT_UPSTREAM=http://app:3000 \
  -e EASYPOT_TRUST_PROXY=1 \
  -e EASYPOT_SECRET=$(openssl rand -hex 24) \
  -e EASYPOT_ADMIN_TOKEN=$(openssl rand -hex 24) \
  -e EASYPOT_FEED_TOKEN=$(openssl rand -hex 24) \
  easypot
# nginx forwards to EasyPot, EasyPot to your app
upstream easypot { server 127.0.0.1:8080; }
server {
  listen 443 ssl;
  location / {
    proxy_pass http://easypot;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For
      $proxy_add_x_forwarded_for;
  }
}
# sidecar next to your app container
- name: easypot
  image: easypot:latest
  ports: [{ containerPort: 8080 }]
  env:
    - { name: EASYPOT_UPSTREAM,
        value: "http://127.0.0.1:3000" }
    - { name: EASYPOT_TRUST_PROXY, value: "1" }
  readinessProbe:
    httpGet: { path: /healthz, port: 8081 }
